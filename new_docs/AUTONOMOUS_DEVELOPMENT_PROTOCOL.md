# AUTONOMOUS_DEVELOPMENT_PROTOCOL

Fluxo: localizar extensão canônica -> implementar server -> contrato de rede -> cliente/UI -> validação -> documentação.

Decisão textual:
- Se muda regra/estado: começar no server.
- Se muda payload: atualizar protocolos dos 2 lados.
- Se muda só UI: manter contrato intacto.
- Se muda schema: migration obrigatória.
